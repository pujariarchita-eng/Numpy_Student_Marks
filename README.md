NumPy Student Marks Analysis

Project Description

This project demonstrates how to use NumPy to perform basic statistical analysis on student marks. A NumPy array is created to store student marks, and various statistical measures are calculated.

Objective

To understand how NumPy can efficiently perform numerical analysis and calculate statistical values.

Technologies Used

* Python
* NumPy
* Jupyter Notebook

Dataset

The project uses a manually created dataset containing marks of 10 students.

marks = np.array([78, 85, 92, 67, 74, 88, 95, 81, 69, 90])

Features

* Create a NumPy array of student marks
* Calculate the mean
* Calculate the median
* Find the maximum marks
* Find the minimum marks
* Calculate the standard deviation
* Display the results clearly

Results

Statistical Measure	Result
Mean	81.9
Median	83.0
Maximum	95
Minimum	67
Standard Deviation	9.24 (approx.)

Conclusion

This project demonstrates how NumPy simplifies numerical calculations. The statistical functions help summarize student performance by identifying the average, middle value, highest and lowest marks, and variation in marks.

How to Run

1. Install Python.
2. Install NumPy using the command:

pip install numpy

3. Open the Jupyter Notebook.
4. Open Numpy_Student_Marks.ipynb.
5. Run all the cells to view the results.

Project File

* Numpy_Student_Marks.ipynb — Jupyter Notebook containing the Python code, statistical calculations, and results.
